# 금융투자 & 자본시장 OX 챌린지

투자 상식과 자본시장 제도를 OX 퀴즈로 확인하는 단일 페이지 웹앱입니다.
빌드 도구·프레임워크 없이 `index.html` 한 장으로 동작합니다. 로고까지 base64로 내장되어
있어 이미지·폰트 등 외부 리소스를 전혀 불러오지 않고, 문항만 `questions.js`에서 읽습니다.
두 파일을 같은 폴더에 두면 웹 배포는 물론 파일을 직접 열어도 동작합니다.

**문제를 바꾸려면 `questions.js`만 수정하면 됩니다.**

## 기능

- **출제 설정** — 문항 수, 문제당 제한시간(10~60초)을 시작 전에 조절
- **타이머 퀴즈** — 남은 시간 실시간 표시, 5초 이하 경고 상태, 시간 초과 시 자동 처리
- **타이머 효과음** — 문제를 푸는 동안 반복 재생. 헤더의 스피커 버튼으로 끄고 켤 수 있고 설정은 브라우저에 기억됩니다
- **즉시 해설** — 정답/오답/시간초과 여부와 해설을 문제마다 바로 안내
- **결과 요약** — 점수와 정답률 구간별 코멘트
- **문제 관리** — 문항 등록·수정·삭제 (임시 편집용. 브라우저 `localStorage`에만 저장)

## 반응형

`320px`부터 데스크톱까지 가로 스크롤 없이 동작합니다.

| 구간 | 주요 처리 |
| --- | --- |
| ~640px | 헤더 2줄 분리, 설정 카드 1열, OX 카드 축소(2열 유지), NEXT 버튼 전폭 |
| ~900px | 여백·타이포 축소 |
| 가로 모드 (높이 560px 이하) | 문항·버튼 압축해 한 화면에 배치 |

- 타이포는 `clamp()`로 유동 스케일링
- hover 효과는 `@media (hover: hover)`로 제한해 터치 기기 잔상 방지
- `env(safe-area-inset-*)`로 노치 대응, `100dvh`로 모바일 주소창 높이 대응
- `prefers-reduced-motion` 존중

## 문항 관리 — `questions.js`

**문항의 원본은 `questions.js` 하나입니다. 이 파일만 고치면 모든 접속자에게 반영됩니다.**
`index.html`은 건드릴 필요가 없습니다.

```js
window.QUIZ_DATA = {
  version: "2026-09-03-a",   // 문항을 바꿀 때 이 값도 함께 바꿔주세요

  questions: [
    { question: "문제 내용", answer: "O", explanation: "정답 해설" }
  ]
};
```

수정 후 배포하면 끝입니다.

```bash
npx vercel@latest deploy --prod --scope djhwangs-projects
```

### version을 왜 같이 바꾸나요

접속자가 관리 화면에서 문항을 고치면 그 수정본이 브라우저에 남습니다.
`version`이 그대로면 그 사람은 계속 자기 수정본을 보게 되고, `version`이 바뀌면
새 공식 문항으로 갱신됩니다. **문항을 바꿨는데 반영이 안 되면 `version`을 확인하세요.**

### 문제 관리 화면의 위치

관리 화면에서의 등록·수정·삭제는 **그 브라우저에만** 저장됩니다(localStorage).
다른 사람에게 공유되지 않으므로 임시 편집·미리보기 용도이며, 공식 문항으로 반영하려면
`questions.js`을 수정해야 합니다. 화면에 상시 안내 배너와 `공식 문항으로 되돌리기`
버튼을 두었습니다.

### 왜 JSON이 아니라 JS 파일인가

`index.html`을 브라우저로 직접 열면(`file://`) 브라우저가 그 페이지를 불투명 출처로
취급해, 같은 폴더의 파일이라도 `fetch()`로는 읽을 수 없습니다. 반면 `<script src>` 는
그 제약을 받지 않습니다. 그래서 문항을 JSON + fetch 가 아니라 JS 파일 + script 태그로
읽습니다. **덕분에 두 파일을 같은 폴더에 두면 더블클릭으로 열어도 정상 동작합니다.**

### 불러오기 실패 시

`questions.js`를 못 읽으면 브라우저에 저장된 문항으로 진행하고 안내 배너를 띄웁니다.
그마저 없으면 오류를 표시하고 시작 버튼을 막습니다. 대부분 `index.html` 옆에
`questions.js`가 없는 경우입니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `questions.js` | **문항 원본.** 문제를 바꾸려면 이 파일만 수정합니다. |
| `index.html` | 앱 전체(HTML+CSS+JS). 로고까지 base64로 내장되어 있습니다. |

로고를 포함한 모든 에셋이 `index.html` 안에 들어 있어 이미지 파일은 따로 없습니다.

**로고 교체** — 새 이미지를 base64로 변환해 `.ci-img`의 `src` 값을 통째로 바꾸면 됩니다.

```bash
base64 -i 새로고.png | tr -d '\n'
```

**현재 로고 추출** — 내장된 data URI에서 원본 PNG(400x159 팔레트 PNG, 13KB)를
그대로 복원할 수 있습니다.

```bash
grep -o 'base64,[^"]*' index.html | head -1 | cut -d, -f2 | base64 -d > kofia-logo.png
```

## 타이머 효과음

효과음은 `index.html`에 base64로 내장되어 있어 별도 파일이 없습니다.
`<audio>` 대신 Web Audio API로 재생합니다 — 2초짜리 짧은 소리를 반복해야 하는데
`<audio loop>`는 반복 지점에 미세한 공백이 생기기 때문입니다.

MP3는 인코딩 과정에서 끝에 무음이 붙습니다(이 파일은 48ms). 그대로 반복하면 그만큼
소리가 비어 끊겨 들리므로, 재생 전에 무음을 잘라내고 이음매를 5ms 페이드 처리합니다.

조정할 수 있는 값은 스크립트 상단에 모여 있습니다.

```js
const SOUND_VOLUME = 1.0;          // 소리 크기 (0 ~ 1)
const SOUND_SILENCE_LEVEL = 0.001; // 이 값 이하를 무음으로 보고 끝을 잘라냄
const SOUND_SEAM_FADE_MS = 5;      // 이음매 딸깍 방지용 페이드 길이(ms)
```

소리는 브라우저 자동재생 정책상 사용자가 페이지를 조작한 뒤에만 납니다.
START 버튼 클릭이 그 조작에 해당하므로 실사용에는 영향이 없습니다.

## 로컬 실행

```bash
python3 -m http.server 8777
# http://localhost:8777
```

Vercel 정적 배포. 빌드 커맨드 없이 루트의 `index.html`을 그대로 서빙합니다.
`main` 브랜치에 push하면 자동 재배포됩니다.
