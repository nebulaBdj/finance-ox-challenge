# 금융투자 & 자본시장 OX 챌린지

투자 상식과 자본시장 제도를 OX 퀴즈로 확인하는 단일 페이지 웹앱입니다.
빌드 도구 없이 `index.html` **한 파일로 완결**됩니다. 로고까지 base64로 내장되어 있어
외부 리소스를 하나도 불러오지 않고, 파일 하나만 어디에 두든 그대로 동작합니다.

## 기능

- **출제 설정** — 문항 수, 문제당 제한시간(10~60초)을 시작 전에 조절
- **타이머 퀴즈** — 남은 시간 실시간 표시, 5초 이하 경고 상태, 시간 초과 시 자동 처리
- **즉시 해설** — 정답/오답/시간초과 여부와 해설을 문제마다 바로 안내
- **결과 요약** — 점수와 정답률 구간별 코멘트
- **문제 관리** — 문항 등록·수정·삭제 (브라우저 `localStorage`에 저장)

## 반응형

`320px`부터 데스크톱까지 가로 스크롤 없이 동작합니다.

| 구간 | 주요 처리 |
| --- | --- |
| ~640px | 헤더 2줄 분리, 설정 카드 1열, OX 카드 축소(2열 유지), NEXT 버튼 전폭 |
| ~900px | 여백·타이포 축소 |
| 가로 모드 (높이 560px 이하) | 문항·버튼 압축해 한 화면에 배치 |

- 타이포는 `clamp()`로 유동 스케일링
- hover 효과는 `@media (hover: hover)`로 제한해 터치 기기 잔상 방지
- `env(safe-area-inset-*)`로 노치 대응, `100dvh`로 모바일 주소창 높이 대응
- `prefers-reduced-motion` 존중

## 데이터

문항은 브라우저별 `localStorage["kofia_quiz_v1"]`에 저장됩니다. 저장된 값이 없으면
`index.html`의 `DEFAULT_QUESTIONS` 7문항이 기본 출제됩니다. 서버에 저장되지 않으므로
기기·브라우저마다 문항이 독립적입니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 앱 전체(HTML+CSS+JS) + 로고 base64 내장. **이 파일 하나면 동작합니다.** |
| `kofia-logo.png` | 로고 원본 에셋(400×159, 팔레트 PNG 13KB). 페이지가 참조하지는 않으며, 로고를 교체할 때 쓰는 소스입니다. |

로고를 바꾸려면 새 이미지를 base64로 변환해 `index.html`의 `.ci-img` `src` 값을 교체하세요:

```bash
base64 -i kofia-logo.png | tr -d "\n"
```

## 로컬 실행

```bash
python3 -m http.server 8777
# http://localhost:8777
```
